# Demonstration generation prompts

The built-in OpenAI image generation tool produced only the two background
sources. Brand text, logos, disclosures and product screenshots are composed by
the deterministic local renderer. No customer data was supplied.

## Governed quality landscape

Use case: `ads-marketing`. Premium B2B SaaS campaign background representing
governed quality operations, traceability, evidence pathways and secure
multi-tenant separation. Deep ink-to-teal architectural space, calm translucent
panels, precise connected paths and document/verification geometry. Wide
composition with clean space on the left. Palette: `#0A2425`, `#087F79`,
`#14A39A`, `#D8F3F0`, tiny `#FF6B57` accents. No text, logos, people, UI,
certification seals, standards marks, watermarks or customer data.

## Continuous improvement square

Use case: `ads-marketing`. Square editorial composition about continuous quality
improvement, audit readiness and evidence connecting decisions to actions. Pale
mineral background with a precise circular quality loop, layered paper/glass
modules, evidence cards, verification points and restrained coral emphasis.
Space on the left for deterministic typography. No text, logos, people, UI,
certification seals, ISO logos, watermarks or customer information.

## Reproduction

1. Start the built web application on loopback port 3100.
2. Run `pnpm --filter @perfect-match/web design:render`.
3. Compare dimensions and SHA-256 values with
   `apps/web/public/brand/design-studio/asset-manifest.json`.

The two generative source images are committed so ordinary reproduction never
requires a provider credential or a new paid generation.
