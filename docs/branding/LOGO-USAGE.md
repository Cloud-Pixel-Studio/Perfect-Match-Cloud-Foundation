# Logo usage

## Conceptos explorados

- A — Precision Loop: ciclo y verificación.
- B — Quality Nexus: sistemas interconectados.
- C — PM Grid: monograma modular.

El sistema final **Aligned Evidence** combina un perímetro gobernado, una ruta de
verificación y un nodo coral. Es más legible y reproducible que el PNG 3D legado.

## Reglas

- Área de seguridad: al menos el diámetro del nodo coral alrededor del mark.
- Tamaño mínimo: 20 px digital para isotipo; 120 px para logo horizontal.
- Usar `pmqms-mark.svg` sobre fondos claros y `pmqms-mark-dark.svg` sobre oscuros.
- Monocromo cuando la reproducción no permita color.
- No rotar, estirar, recolorear parcialmente, añadir sombras ni separar piezas.
- El nombre accesible pertenece al enlace/contenedor; el gráfico repetido puede
  usar `alt=""`.

La originalidad visual no garantiza disponibilidad jurídica. Una búsqueda de
similitud, registro y clases debe realizarla asesoría especializada antes de
registro comercial definitivo.
