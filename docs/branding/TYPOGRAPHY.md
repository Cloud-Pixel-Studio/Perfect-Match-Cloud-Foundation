# Typography

Inter Variable 5.3.0 es la familia oficial para producto y marketing: licencia
OFL, soporte latino, excelente lectura de datos y una sola descarga variable.
No se introduce una segunda fuente hasta demostrar una necesidad de marca que
justifique costo y mantenimiento.

- Display: `--pm-text-3xl`, 700, tracking negativo moderado.
- Page title: `--pm-text-2xl`, 700.
- Section title: `--pm-text-xl`, 650–700.
- Body: 1 rem, 400, line-height 1.6.
- Label: .875 rem, 650.
- Caption/data: .75 rem; evitarlo para instrucciones esenciales.
- Código/IDs: `--pm-font-mono` solo en identificadores técnicos.

No usar mayúsculas extensas; reservar tracking positivo para eyebrows cortos.
