# Asset inventory

## Sistema vectorial

- `brand/concepts/concept-{a,b,c}-*.svg`: exploraciones.
- `brand/selected/pmqms-mark.svg`: isotipo claro.
- `pmqms-mark-dark.svg`, `pmqms-mark-mono.svg`: variantes.
- `pmqms-horizontal.svg`, `pmqms-vertical.svg`: lockups.
- `pm-monogram.svg`, `favicon.svg`, `app-icon.svg`.

## Raster

- Mark 128/512 px, app icon 192/512 px, Apple 180 px, favicon 64 px.
- Lockups horizontal 620 px y vertical 720 px.
- `brand-board.svg` y `raster/brand-board-1440.png`: lámina de identidad.
- `hero-quality-network.png`: recurso original generado con imagegen integrado
  al catálogo; sin texto, logos, personas ni afirmaciones comerciales.
- `social/og-perfect-match-qms.svg` y PNG 1200×630: Open Graph.
- `social/linkedin-company.svg` y PNG 1200×1200: plantilla editable.

Los SVG son fuente maestra. Los PNG son exportaciones. `brand-mark.png` se
conserva temporalmente como legado sin usar para facilitar rollback.
